# P001B-S003 frozen experiment — cyclic 12-support families, v1

DATE: 2026-10-14. FROZEN IN GITHUB BRANCH BEFORE COMPUTATION. Do not change this file after the run.

**Mathematical question:** Among all simple 3-uniform families invariant under translation of Z/12Z, with no four-petal sunflower of any core size (including empty), what is the maximum number of triples? This is an intentionally restricted n=12 symmetry class, NOT an exhaustive n=12 search and NOT a universal f(3,4) bound.

**Exact finite population:** Enumerate all 220 triples of residues 0,...,11; partition under the action x -> x+1 mod 12. Prove orbit sizes are 12 except for the unique size-four orbit {{i,i+4,i+8}:i=0,1,2,3}; hence precisely 18 size-12 orbits. Four triples in the exceptional orbit are mutually disjoint and automatically forbidden, so omit every candidate containing that orbit. The published link-degree cap d(v)<=10 implies any sunflower-free translation-invariant family can include at most three ordinary (size-twelve) orbits, since each adds degree 3 at each vertex. Enumerate the complete, *unlabelled-by-choice* population of combinations of 0,1,2,3 of the 18 orbits: 1+18+153+816=988 candidates. No further symmetry pruning, no SAT/MILP heuristics, no other families searched. Empty family included.

**Controls before run:** a hardcoded four disjoint triples must be rejected (empty core); common singleton-core four petals and pair-core four petals rejected; four triples with unequal pairwise SET intersections accepted; duplicate triples cause error. Reconstruct explicit source F39 from 3 groups, nine a+same-group pairs, 27 between-group labelled triples, and verify exactly 39 distinct edges; full quartet oracle and independent matching/link/pair-codegree verifier must both pass. Check orbit decomposition sums to C(12,3)=220, exactly 18 full orbits and 1 short orbit; short orbit visibly a 4-disjoint witness.

**Two independent oracles:** (A) full six-set-intersection check of EVERY quartet in a candidate (may short-circuit at first forbidden quartet); (B) no matching of 4 in 3-uniform family (empty core), no matching of 4 in any vertex's link (one-point core), and no pair codegree >=4 (two-point core). Both must agree on all candidate classifications, not merely winners. A rejected family needs a witness from (A) and a rejection via (B). No unchecked shortcut allowed.

**Execution:** Python 3.x standard library; deterministic lexicographic combinations, no random seed, no optional solver. One complete run, 120-second cap inclusive controls and classification; if cap is reached, return INCONCLUSIVE with processed count (never call it exhaustive). Candidate record includes number of orbit subsets per size and free counts per size; winning ordinary orbits and a lexicographic triple list with SHA256. Archive complete run record and source. Incomplete or inconsistent result => STOP without a maximum claim. Retain failures and the case (if any) of translation-invariant degree10 + codegree<=3 but a sunflower.

**Coverage proof:** Translation invariance exactly means a union of complete orbits. A 3-element set with nontrivial stabilizer in the cyclic group of order 12 must have stabilizer order 3 (free action on each point), hence be an orbit of subgroup {0,4,8}; all four cosets form one four-member translation orbit. All other triple orbits have 12 members. Under the degree cap, only 0-3 ordinary orbits are admissible. Each orbit collection is visited exactly once by combinations; oracles test full three-core semantic criterion. No step assumes n=12 is universally sufficient.
