# Mathematical and research standards

* **Definitions**: each edge has cardinality 3, edges are distinct. A 4-sunflower is four distinct edges with all 6 pairwise **set intersections identical**, including EMPTY kernel. Distinguish an ambient-ground-set statement from an edge witness.
* **Proof**: provide exact statement, complete reproducible proof and independent adversarial checks. Citation or code alone is insufficient. Never infer universal upper bound from a finite ambient cutoff without independently proved covering reduction.
* **Construction**: actual list of >=40 distinct canonical triples, independently verified and hashed; list all input universe and checker metadata. Computational searches must freeze scope, symmetry and resource bounds before execution.
* **Literature**: preserve preprint versions/links and attribution; independently check any claimed novel inequality against post-2026 work; silence is not novelty.
* **Verification**: source checker code + tests/known controls + GitHub PR/run/job/commit evidence; CI tests governance only, not proof correctness. Record absent checks as ABSENT_NOT_PASS and inaccessible protection as UNKNOWN.
* **External actions**: no Lean, Palomar, manuscript, outreach or submission without new owner authority.
