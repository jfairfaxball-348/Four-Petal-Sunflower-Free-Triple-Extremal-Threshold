Archive user invocation verbatim when possible. Choose ONE bounded original target, freeze any nontrivial experiment plan *before* running it and retain failed methods. Exit: update STATE, CLAIMS, SOURCES, novelty and decisions, session history and closeout, and exactly one successor prompt FUTURE only; validate locally and on actual PR SHA. Nonforce commit / ordinary two-parent merge after required hosted checks. Independently verify merged main/push CI. No phantom CI. Every fifth/tenth sessions audit progress/strategy. No speculative parent or child runs. Parent controls portfolio; P001B child controls mathematics.
