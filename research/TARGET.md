# Finite extremal target

Let f(3,4) = max{|F| : F is a finite set of distinct 3-element subsets of some finite V and F has no four distinct edges with six exactly equal pairwise intersections}. The common kernel K may be ∅, {x} or {x,y}. Triple multiplicities are forbidden. V can be shrunk to ∪F without changing the property but |∪F| has NO justified fixed universal bound in the current bootstrap.

Cited preprint Axante et al. arXiv:2609.06175v1 (Sept 2026), abstract reports 39 <= f(3,4) <= 49; lower explicit, upper computer-assisted. Full mathematical and machine certificates not yet independently audited by this project. Target NEW <=48 theorem or >=40 certified construction, possibly exact value. A finite search for a bounded number of vertices cannot certify <=48 without global bound proof. New work must first reconstruct and check known 39 and 49 methods. **No fixed-rank gain is an Erdős–Rado asymptotic breakthrough.**
